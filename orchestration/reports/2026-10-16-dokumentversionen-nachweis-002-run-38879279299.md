Eine PDF wurde bereits verarbeitet. Dann kommt eine korrigierte Fassung. Erkennt dein KI-Agent, was sich geändert hat?

In vielen automatisierten Abläufen wird nur gespeichert: „Datei schon bearbeitet.“ Für einen verlässlichen Prozess reicht das nicht. Denn ein Dokumentname kann gleich bleiben, obwohl sich Inhalt, Preis oder Liefertermin geändert haben.

Mein Vorschlag für einen kontrollierbaren Ablauf:

• Originaldatei und Eingangszeit sichern.
• Jede Version über eine digitale Prüfsumme wiedererkennen.
• Bei neuer Prüfsumme die relevanten Felder mit der letzten Fassung vergleichen.
• Änderungen dokumentieren und kritische Abweichungen vor der Übernahme freigeben lassen.

Wichtig: Eine Prüfsumme zeigt, DASS sich Daten geändert haben. Sie erklärt nicht, WAS die Änderung fachlich bedeutet. Dafür braucht es den tatsächlichen Vergleich und klare Entscheidungsregeln.

KI kann diese Vorarbeit beschleunigen. Nachvollziehbarkeit entsteht aber erst, wenn Quelle, Version, Ergebnis und Freigabe zusammengehören.

Wie löst ihr Änderungen an bereits eingelesenen Dokumenten?

Ein KI-Agent verarbeitet eine Rechnung. Am nächsten Tag kommt dieselbe Rechnung noch einmal – diesmal mit einem korrigierten Betrag.

Was passiert jetzt? Wird sie als „schon verarbeitet“ ignoriert? Oder erkennt der Ablauf, dass eine wichtige Änderung vorliegt?

Ich würde zwei Dinge klar trennen: Erstens, ob eine Datei bereits bekannt ist. Zweitens, ob ihr Inhalt seitdem verändert wurde.

Dafür lässt sich die Originalversion mit Eingangszeit und digitaler Prüfsumme speichern. Kommt eine neue Fassung, werden die relevanten Angaben verglichen. Auffällige Änderungen gehen zur Prüfung, bevor Werte in andere Systeme übernommen werden.

Die KI kann beim Vergleichen helfen. Sie sollte aber nicht eigenmächtig entscheiden, dass ein geänderter Betrag automatisch übernommen werden darf.

So wird aus „Die Datei wurde bearbeitet“ die bessere Frage: „Welche Version wurde verarbeitet – und was wurde danach geändert?“
