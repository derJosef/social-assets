# Öffentliches Medienverzeichnis

Dieser Bereich dient der dauerhaft öffentlich abrufbaren Medienbereitstellung für **ausschließlich freigegebene** Buffer-Beiträge.

Zielordner für Binärdateien:
- `media/images/`: JPEG, PNG, WebP, auch Vorschau-Cover für PDF-Dokumente.
- `media/documents/`: LinkedIn-Dokumente (PDF-Karussells).

Medien-URL-Schema:
`https://raw.githubusercontent.com/derJosef/social-assets/main/media/images/datei.png`

`https://raw.githubusercontent.com/derJosef/social-assets/main/media/documents/datei.pdf`

**Wichtig:** Das Repository ist öffentlich. Keine privaten Aufnahmen, vertraulichen Dokumente oder fremden Bilder ohne Nutzungsrechte hier einstellen.

Buffer verarbeitet Medien über öffentlich erreichbare URLs, nicht über einen lokalen Upload. Die URL muss bis zur späteren Veröffentlichung erreichbar bleiben. Die zugehörigen JSON-Entwürfe in `drafts/` lösen noch **keinen** Versand aus. Erst eine ausdrücklich freigegebene neue JSON-Datei unter `ready-for-buffer/` startet den automatischen Entwurfstransfer.

Offizielle Buffer-Dokumentation: https://developers.buffer.com/guides/hosting-media.html
