# social-assets
Social-Media-Assets und Metadaten für automatisierte Veröffentlichung


## Autonome geprüfte Buffer-Entwürfe (AI Agent Builder)

Seit 09.10.2026 darf der Agent Themen, Texte und Original-Logo-Grafiken für **AI Agent Builder** ohne Einzelgenehmigung vorbereiten und nach bestandenem [Quality-Gate](docs/AUTONOMOUS_BUFFER_POLICY.md) als **unveröffentlichte Buffer-Entwürfe** übergeben. Plattformspezifische Veröffentlichungszeiten können automatisch geplant werden. Das Aktivieren der zeitgesteuerten Veröffentlichung in Buffer bleibt **gesondert genehmigungspflichtig**.

Nachgewiesener Live-Test: [GitHub Actions #37898575725](https://github.com/derJosef/social-assets/actions/runs/37898575725), danach [unabhängige Statusprüfung #37898698353](https://github.com/derJosef/social-assets/actions/runs/37898698353): LinkedIn, Facebook und Instagram jeweils `draft`, `dueAt=null`.
